# 연구정책국 회의실 예약

화이트보드 달력을 대신하는 회의실 예약 웹앱입니다. 자리에서 빈 시간을 보고 바로 예약하며, 먼저 신청한 사람이 확정됩니다. 모든 등록·수정·취소는 이력으로 남습니다.

- 화면: 정적 HTML·JS (`public/`)
- 서버: Vercel 서버리스 함수 (`api/`, `lib/`)
- 데이터베이스: Postgres (Vercel에서 Neon 연결)
- 비용: 국 단위 이용량이면 Vercel·Neon 무료 요금제 범위 안에서 운영 가능

---

## 1. 무엇을 할 수 있나

**직원**
- 달력에서 날짜를 누르면 그날 시간표가 열리고, 날짜 아래 띠로 어느 시간대가 찼는지 한눈에 보입니다.
- 시간표의 빈 칸을 눌러 시작, 한 번 더 눌러 끝을 고르면(또는 끌어서) 신청서에 시간이 채워집니다.
- 회의명·신청자·부서·내선번호·참석 인원·메모를 쓰고 4자리 비밀번호를 정하면 예약 완료.
- 매주 반복 예약(최대 12주). 겹치는 주는 건너뛰고 알려 줍니다.
- 예약 완료 후 **내 캘린더에 추가**(.ics 파일, 아웃룩·구글 캘린더에서 열림).
- **내 예약** 탭에서 이름으로 찾아 수정·취소(비밀번호 확인).
- 부서마다 색이 달라 누가 쓰는지 바로 구분됩니다.
- 30초마다 자동 새로고침되어 다른 사람이 방금 잡은 예약도 반영됩니다.

**관리자**
- 모든 예약 수정·취소·복구(비밀번호 불필요, 사유 기록).
- **순서 바꾸기**: 같은 날 두 회의를 체크하면 시간대를 맞바꿉니다. 각 회의 길이와 사이 간격은 유지됩니다.
- **대리 등록**과 **예약 불가 시간**(시설 점검, 국장 주재 회의 등) 설정, 반복 가능.
- **변경 이력**: 누가 언제 무엇을 바꿨는지 전부 조회.
- **이용 통계**: 월별 건수·이용 시간·이용률, 부서별·시간대별 분포.
- **엑셀(CSV) 내려받기**: 기간별 전체 예약 대장.

**회의실 앞 현황판**
- 주소 뒤에 `?view=board`를 붙이면(상단 **현황판 열기**) 큰 글씨로 지금 사용 중인지, 오늘 일정이 나옵니다. 남는 태블릿을 회의실 문 옆에 두면 됩니다.

**선착순 보장 방식**
데이터베이스에 "같은 시간대에 활성 예약은 1건만" 규칙을 걸어 두었습니다. 두 사람이 같은 시간을 동시에 눌러도 먼저 저장된 1건만 성공하고, 나머지는 "이미 예약된 시간입니다: 10:00~11:00 ○○회의(홍길동/연구정책과)"처럼 누가 잡았는지와 함께 안내됩니다. 10건을 동시에 보내는 시험에서 1건만 성공하는 것을 확인했습니다.

## 2. 배포하기 (처음 한 번, 20분 정도)

준비물: GitHub 계정, Vercel 계정(GitHub로 가입하면 편합니다).

### ① GitHub에 올리기
1. GitHub에서 **New repository** → 이름 예: `rpb-meeting-room` → **Private** 선택 → Create.
2. 새 저장소 화면에서 **uploading an existing file** 클릭.
3. 압축을 푼 `meeting-room` 폴더 **안의 내용 전체**(api, lib, public, scripts 폴더와 package.json, vercel.json, README.md 등)를 끌어다 놓고 **Commit changes**.
   - `.gitignore`, `.env.example`처럼 점으로 시작하는 파일은 운영체제에 따라 숨겨져 안 올라갈 수 있는데, 없어도 동작에는 지장 없습니다.

### ② Vercel에 연결
1. Vercel 대시보드 → **Add New… → Project** → 방금 만든 GitHub 저장소 **Import**.
2. Framework Preset은 **Other** 그대로, 나머지 설정도 건드리지 말고 **Deploy**.
   - 이 시점에는 데이터베이스가 없어 화면에 오류가 나는 게 정상입니다.

### ③ 데이터베이스 연결 (Neon)
1. 프로젝트 화면 상단 **Storage** 탭 → **Create Database** → **Neon** 선택.
2. 지역(Region)은 목록에서 **한국과 가장 가까운 아시아 지역**을 고르세요. 요금제는 Free.
3. 만든 데이터베이스에서 **Connect Project** → 이 프로젝트 선택 → 연결.
   - `DATABASE_URL` 환경변수가 자동으로 들어갑니다. 테이블은 앱이 처음 실행될 때 스스로 만듭니다.

### ④ 환경변수 입력
프로젝트 **Settings → Environment Variables**에서 아래를 추가합니다.

| 이름 | 필수 | 설명 |
|---|---|---|
| `ADMIN_PASSWORD` | 필수 | 관리자 로그인 비밀번호 |
| `APP_SECRET` | 권장 | 아무 글자나 30자 이상. 예약 비밀번호 암호화에 쓰이니 **처음 정한 뒤 바꾸지 마세요** |
| `ACCESS_CODE` | 선택 | 설정하면 처음 접속할 때 이 코드를 물어봅니다(국 직원에게만 공유). 기기마다 한 번만 입력 |
| `ROOM_LOCATION` | 선택 | 예: `본관 3층 312호` |
| `ROOM_CAPACITY` | 선택 | 예: `20` |

운영 규칙(이용 시간, 최대 이용 시간, 예약 가능 기간, 부서 목록 등)도 `.env.example`에 적힌 이름으로 바꿀 수 있습니다.

### ⑤ 다시 배포
**Deployments** 탭 → 맨 위 배포의 `⋯` → **Redeploy**. 끝나면 `https://프로젝트이름.vercel.app` 주소로 접속합니다.

이후에는 GitHub의 파일을 고치면 Vercel이 자동으로 다시 배포합니다.

## 3. 운영 전에 확인할 점

- **업무망 접속 여부**: 망분리된 업무용 PC에서 `vercel.app` 주소가 열리는지 먼저 확인해 주세요. 막혀 있다면 인터넷망 PC·휴대전화에서만 쓰거나, 정보화 담당 부서와 협의가 필요합니다.
- **개인정보·보안**: 이 앱은 이름, 부서, 내선번호만 저장합니다. 그래도 외부 클라우드에 직원 정보를 두는 것이므로 기관 정보보안 기준에 맞는지 담당 부서에 확인하는 것이 안전합니다. 외부인 접근을 줄이려면 `ACCESS_CODE`를 설정하세요(검색엔진 노출도 차단되어 있습니다).
- **요금제 약관**: Vercel 무료(Hobby) 요금제는 개인·비상업 용도로 안내되어 있습니다. 기관 공식 서비스로 운영할 계획이면 약관을 확인하고 필요 시 유료 요금제를 검토하세요.
- **휴일 표시**: 양력 고정 공휴일은 자동으로 빨간 날 표시되고, 2027년 설·부처님오신날·추석과 대체공휴일은 기본값으로 넣어 두었습니다. 그 외 휴일(임시공휴일, 2028년 이후 명절 등)은 `HOLIDAYS` 환경변수에 `2028-01-26,2028-01-27`처럼 추가하세요. 휴일 표시는 색깔만 바꾸며 예약을 막지는 않습니다.

## 4. 자주 묻는 문제

| 증상 | 해결 |
|---|---|
| "DATABASE_URL 환경변수가 설정되지 않았습니다" | ③ 데이터베이스 연결 후 ⑤ 다시 배포 |
| "관리자 비밀번호(ADMIN_PASSWORD)가 설정되지 않았습니다" | ④에서 `ADMIN_PASSWORD` 추가 후 다시 배포 |
| 예약 비밀번호를 잊었다 | 관리자가 [수정]에서 비밀번호 재설정 또는 대신 수정·취소 |
| 접속 코드를 바꾸고 싶다 | `ACCESS_CODE` 변경 후 다시 배포. 각 기기에서 새 코드를 한 번 입력 |
| 화면은 열리는데 예약 목록이 안 뜬다 | Vercel 프로젝트 → **Logs**에서 오류 문구 확인 |

## 5. 파일 구성

```
api/bookings.js     직원용 API (조회·예약·수정·취소)
api/admin.js        관리자용 API (로그인·관리·이력·통계·내보내기)
lib/service.js      예약 규칙과 데이터베이스 처리
lib/db.js           DB 연결, 테이블 자동 생성(중복 방지 규칙 포함)
lib/config.js       운영 규칙 기본값
public/             화면(index.html, app.js, style.css)
scripts/            로컬 개발용 서버
```

데이터는 `bookings`(예약)와 `booking_logs`(변경 이력) 두 테이블에 저장됩니다. 취소해도 지우지 않고 상태만 바꾸므로 이력이 그대로 남습니다.

## 6. 내 PC에서 실행해 보기 (선택)

Node.js 20 이상과 Postgres가 있으면:

```bash
npm install
DATABASE_URL=postgresql://사용자@localhost:5432/db이름 ADMIN_PASSWORD=test npm run dev
# http://localhost:3000
```
